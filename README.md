# Aditya Maurya — Portfolio

A modern, responsive React + Vite portfolio for software-development applications.

- React.js
- JavaScript
- Vite
- Lucide React
- Responsive CSS

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
